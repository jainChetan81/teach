Herdr cheat sheet

The 90% you'll actually use. Source of truth: herdr.dev/docs.

Everyday

Do thisHow
Start / reattachherdr (starts or attaches to the background server)
Detach, keep everything runningctrl+b q
New pane / splitprefix keys or click-drag in the TUI (mouse is first-class)
Reload configprefix + Shift+r (config at ~/.config/herdr/config.toml)
Richer agent stateherdr integration install claude (also codex, copilot, …)

Remote (the capstone moves)

Do thisHow
Attach from another machinessh you@machine then herdr
Thin-client attach (no remote shell)herdr --remote workbox or herdr --remote ssh://you@host:2222
Repeat targetsname them in ~/.ssh/config, then herdr --remote <name>
From a phoneBlink Shell (Mosh-capable) or Termius → SSH → herdr
Survive Wi-Fi → cellularuse mosh instead of ssh as the transport

Socket API (agents driving herdr)

herdr workspace create --cwd ~/project --label api
herdr tab create --label logs
herdr pane split 1-1 --direction right
herdr pane run 1-2 "just test"
herdr wait agent-status 1-1 --status done
herdr pane read 1-2 --source recent-unwrapped

Mental model (one line)

The server holds the PTYs; every terminal — Mac, phone, VPS — is a disposable view onto them. Mosh keeps the connection alive; herdr keeps the work alive.
