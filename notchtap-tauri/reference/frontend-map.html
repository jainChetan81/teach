NotchTap frontend map

The smallest useful model of the real application. Updated 2026-08-16 after the Big Cleanup: hooks now live in src/hooks/, shared helpers in src/lib/; weather and media are gone.

The main idea

The frontend renders a state machine owned mostly by Rust. React receives state, chooses a surface, and turns that surface into HTML, CSS, and motion.

The complete path

external input ↓ Rust core ↓ Tauri event carrying JSON React custom hook ↓ App.tsx and components ↓ CSS and Motion ↓ macOS webview pixels

You do not need all of Rust to fix the frontend. Start at the custom hook. Move one box left only when the value arriving there is wrong.

Two frontends live in one app

Vite builds both entries. Tauri places each build inside a separate webview. The overlay stays receive-only. The settings window can invoke a fixed command list.

One event, end to end

Use slot-state as the first trace.

  1. The Rust engine decides whether the slot is empty or showing a notification.
  2. Rust emits a JSON payload named slot-state.
  3. hooks/useSlotState.ts listens for that event.
  4. The hook validates every field before it updates React state.
  5. App.tsx reads the state and passes it to StatusRailCard.
  6. StatusRailCard derives classes, content, and the active below-block.
  7. CSS and Motion turn those classes and elements into the visible card.

Why the validator matters

Tauri events carry JSON and have no shared TypeScript type at runtime. The hook treats the payload as unknown. A malformed payload becomes a safe empty state.

How to locate a UI defect

  1. Write the expected and actual visual states.
  2. Find the final DOM element in the web inspector.
  3. Find the component that produced that element.
  4. Find the prop or hook value that chose its state.
  5. Stop when you find the first wrong value.
  6. Write a failing test at that boundary.
  7. Change the smallest owner and verify on hardware.

A CSS symptom can start in Rust. A missing card can start in a TypeScript validator. A jumping animation can start with two React children mounted at once. Follow the value.

The first retrieval check

A notification has the correct text in useSlotState, but its manifest opens at the wrong time. Where do you look next?

Show the answer

Inspect the component prop and render condition. The wire value is already correct, so follow it forward into rendering.
