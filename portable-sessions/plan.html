Capstone: Portable Agent Sessions the point of it all

Learn how herdr preserves sessions → apply the same model to t3code → carry a live agent session from one device to another over SSH and Tailscale.

Why this capstone exists

This is the project the ai-tooling, networking, and rust tracks feed into. herdr already solved session persistence one way (a background server holding real PTYs; thin clients attach over a Unix socket or SSH). t3code solved it another way (SQLite-backed session store behind a web GUI). The question: can you carry a session between your devices as cleanly as herdr carries one between terminals — and what would t3code need for that?

The open question is not "what would this require," it's "set it up and demo it."

You've finished the capstone when

You start an agent session on one machine, walk to another device, and continue it — and you can explain exactly which layer (PTY server, SQLite store, SSH, Tailscale) made each part of that possible.
