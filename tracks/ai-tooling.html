AI Tooling & Coding Agents active

How Claude Code and coding agents actually work — tokens, context windows, the agent loop — then MCP, PAL MCP, and forking t3code to run on your Kimi subscription.

Why this track exists

You use coding agents every day, but from the outside. Understanding the loop (prompt → model → tool call → result → repeat), the token economy, and the MCP protocol turns you from a user into someone who can extend the tools — culminating in a t3code fork that runs on the subscription you already pay for.

Objectives

  • Explain a coding agent's loop, token counting, and context-window limits from memory.
  • Explain what MCP is (hosts, clients, servers; tools, resources, prompts) and build one toy server.
  • Understand PAL MCP's provider-routing role and trace one call through it.
  • Run t3code locally, map its architecture, and spike adding a Kimi provider to your fork.
