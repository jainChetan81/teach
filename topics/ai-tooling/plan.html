AI Tooling & Coding Agents active

How coding agents actually work — tokens, context windows, the agent loop — then MCP, PAL MCP, and t3code: run it, map it, fork it onto your Kimi subscription.

Why this track exists

You use coding agents every day, but from the outside. Understanding the loop (prompt → model → tool call → result → repeat), the token economy, and the MCP protocol turns you from a user into someone who can extend the tools. The t3code module feeds directly into the portable-sessions capstone.

Objectives

  • Explain a coding agent's loop, token counting, and context-window limits from memory.
  • Explain MCP (hosts, clients, servers; tools, resources, prompts) and build one toy server.
  • Understand PAL MCP's provider-routing role and trace one call through it.
  • Run t3code, map its architecture (Effect layers, provider adapters, SQLite session store), and spike a Kimi provider in your fork.
