Networking: SSH · Herdr · Tailscale · VPS queued

From "I type ssh and it works" to understanding every layer — the plumbing that makes the portable-sessions capstone possible.

Why this track exists

herdr's persistence works because of two things: a server that never dies, and SSH as the transport that reaches it from anywhere. Tailscale removes the "from anywhere" friction. This track makes each layer explicit — SSH handshakes, herdr's client-server split, WireGuard NAT traversal — so that moving a session between devices stops being magic and starts being engineering.

Objectives

  • Use SSH fluently: keys, config, agent, port forwarding — no copy-pasting from old notes.
  • Explain herdr's client-server architecture and how sessions survive detach, sleep, and SSH drops.
  • Explain WireGuard/Tailscale: key pairs, NAT traversal, DERP relays — then build a toy tunnel.
  • Run and harden a VPS you actually use for something.
