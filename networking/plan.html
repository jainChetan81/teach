Networking: SSH · Tailscale · VPS queued

From "I type ssh and it works" to understanding every layer — the plumbing that makes the portable-sessions capstone possible. (Herdr has its own folder: ../herdr.)

Why this track exists

herdr's persistence works because of two things: a server that never dies, and SSH as the transport that reaches it from anywhere. Tailscale removes the "from anywhere" friction. This track makes each layer explicit — SSH handshakes, WireGuard NAT traversal — so that moving a session between devices stops being magic and starts being engineering.

Objectives

  • Use SSH fluently: keys, config, agent, port forwarding — no copy-pasting from old notes.
  • Explain WireGuard/Tailscale: key pairs, NAT traversal, DERP relays — then build a toy tunnel.
  • Run and harden a VPS you actually use for something (an always-on herdr server is the obvious candidate).
  • Explain why a terminal session normally dies when your IP changes, and how mosh's UDP design gets around it — then build a toy version of that idea yourself.
